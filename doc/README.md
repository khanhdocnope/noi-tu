# BOT DISCORD: "NUÔI MỘT THỨ"

Discord bot game theo mô hình **virtual pet + progression + economy + exploration**.

## Triết lý thiết kế

> Người chơi không chỉ "nuôi pet", mà đang nuôi một sinh vật dần thay đổi theo thời gian.

## Tech Stack

- Node.js
- TypeScript (strict mode)
- discord.js
- Supabase (PostgreSQL + Storage + Auth)
- Hugging Face Datasets (artwork storage)

## Tính năng MVP

- Random nhận pet
- Chăm sóc pet (feed, play, rest)
- Hệ thống economy (Coin)
- Hunting / Exploration
- Shop & Inventory
- Level progression
- Artwork theo level
- Daily reward
